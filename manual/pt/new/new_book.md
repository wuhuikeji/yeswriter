Criar livro
---

#### Etapas

1. Acesse a página “Pastas”.
2. Toque em “+”.
3. Digite o título do livro.

![](imgs/new_book1.png)

#### Dicas

1. Os livros criados na página “Pastas” aparecem nessa página. Os livros criados dentro de uma pasta aparecem nessa pasta.

2. Toque em “Imagem personalizada” para escolher uma imagem do álbum como capa do livro.

3. Toque no botão redondo colorido à direita do título do livro para definir a cor do título.

4. Toque em “Descrição” para adicionar uma introdução ao livro.

5. Toque em “Esquema de tamanho da fonte” para usar um tamanho global uniforme ou personalizar tamanhos locais.
