Standardbuch festlegen
---
#### Schritte

1. Gehen Sie zur Seite „Neueste“.

2. Tippen Sie auf „Mehr“.

3. Wählen Sie „Standardbuch wechseln“.

![](imgs/switch_default_book.png)

#### Hinweise

Nachdem Sie ein Standardbuch festgelegt haben, kann YesWriter direkt das gewünschte Buch öffnen.
