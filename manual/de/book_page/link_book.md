Materialbücher verknüpfen
---
#### Schritte

1. Tippen Sie auf die Schaltfläche „⊕“.

2. Tippen Sie auf „Bücher verknüpfen“.

3. Wählen Sie die Bücher aus, die Sie verknüpfen möchten. Sie können mehrere Bücher verknüpfen.

![](imgs/link_book1.png)

#### Hinweise

Bücher können miteinander verknüpft werden. Beim Schreiben eines Hauptmanuskripts können Sie Materialbücher verknüpfen, um sie zentral zu verwalten und jederzeit schnell aufzurufen.
