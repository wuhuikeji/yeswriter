Ordner stapelweise verwalten
---

#### Schritte

1. Gehen Sie zur Seite „Ordner“.

2. Drücken Sie den Zielordner länger.

3. Tippen Sie im Pop-up-Menü auf „Mehrere auswählen“.

4. Wählen Sie die gewünschten Ordner aus und verschieben, löschen oder exportieren Sie sie anschließend gesammelt.
