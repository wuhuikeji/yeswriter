Text verknüpfen
---

Beim Erstellen einer Aufgabe können Sie einen verknüpften Text auswählen.

So können Sie auf eine Aufgabe tippen und schnell zum zugehörigen Text springen.

Beim Anzeigen des Textes sehen Sie außerdem Markierungen zu Aufgaben, die Sie an die Erledigung zugehöriger Aufgaben erinnern.
