Buch erstellen
---

#### Schritte

1. Gehen Sie zur Seite „Ordner“.
2. Tippen Sie auf „+“.
3. Geben Sie den Buchtitel ein.

![](imgs/new_book1.png)

#### Hinweise

1. Bücher, die auf der Seite „Ordner“ erstellt werden, erscheinen dort. Bücher, die innerhalb eines Ordners erstellt werden, erscheinen in diesem Ordner.

2. Tippen Sie auf „Benutzerdefiniertes Bild“, um ein Bild aus Ihrem Album als Buchcover auszuwählen.

3. Tippen Sie auf die farbige runde Schaltfläche rechts neben dem Buchtitel, um die Titelfarbe festzulegen.

4. Tippen Sie auf „Beschreibung“, um eine Einführung für das Buch hinzuzufügen.

5. Tippen Sie auf „Schriftgrößenschema“, um eine einheitliche globale Schriftgröße zu verwenden oder lokale Schriftgrößen anzupassen.
