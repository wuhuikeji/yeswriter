Restore Data
---
#### Steps

1. Go to the Me page.

2. Tap Backup & Restore.

3. Tap a backup file.

4. Select the restore options you need.

5. Tap Confirm to start restoring data.

![](imgs/data_recovery1.png)

#### Tips

When restoring backup data, three strategies are available:
- Overwrite same: replace the current text with the backup content.
- Skip same: when the backup content is the same as the current text, keep the current text unchanged.
- Auto merge: merge backup and existing texts based on the latest modification time.

Choose the right strategy for your needs and back up regularly to prevent data loss.
