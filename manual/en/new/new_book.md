Create Book
---

#### Steps

1. Go to the Folders page.
2. Tap +.
3. Enter the book title.

![](imgs/new_book1.png)

#### Tips

1. Books created on the Folders page appear on that page. Books created inside a folder appear in that folder.

2. Tap Custom Image to choose an image from your album as the book cover.

3. Tap the colored round button on the right side of the book title to set the title color.

4. Tap Description to add an introduction for the book.

5. Tap Font Size Scheme to use a unified global font size or customize local font sizes.
