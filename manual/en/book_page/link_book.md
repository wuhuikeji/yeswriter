Link Reference Books
---
#### Steps

1. Tap the ⊕ button.

2. Tap Link Books.

3. Select the books you want to link. You can link multiple books.

![](imgs/link_book1.png)

#### Tips

Books can be linked to each other. When writing a main manuscript, you can link reference books for centralized management and quick access.
