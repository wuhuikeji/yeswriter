Sauvegarder dans le cloud avec Jianguoyun
---
Jianguoyun fournit un espace cloud gratuit. Vous pouvez y sauvegarder vos données de manière sûre et pratique, afin de restaurer rapidement tous vos textes même après un changement d’appareil ou une réinstallation de l’application.

### Étapes

Ouvrez le site de Jianguoyun, puis inscrivez-vous ou connectez-vous avec la version web.

(Si vous ouvrez Jianguoyun sur un téléphone, choisissez « Connexion à la version web ». Si vous n’avez pas de compte, créez-en un d’abord. Après la connexion, passez à l’onglet « Moi » en bas et touchez « Demander le site de bureau » pour accéder à la version de bureau.)

1. Après la connexion, cliquez sur votre nom d’utilisateur en haut à droite et choisissez « Informations du compte ».
2. Passez à l’onglet « Options de sécurité » en haut.
3. Faites défiler jusqu’à « Gestion des applications tierces », cliquez sur « Ajouter une application », saisissez un nom comme YesWriter, puis cliquez sur « Générer un mot de passe ».
4. Selon les informations affichées, allez dans YesWriter -> Sauvegarde et restauration -> Sauvegarde cloud, sélectionnez WebDAV, puis renseignez :
    * **Adresse du serveur et nom du compte : renseignez-les comme indiqué sur la page web.**
    * **Mot de passe : utilisez le mot de passe d’application généré, visible dans la liste des applications Jianguoyun.**

Une fois la configuration terminée, vous pouvez synchroniser les textes avec Jianguoyun. En cas de changement d’appareil ou de réinstallation de l’application, connectez-vous à Jianguoyun pour restaurer rapidement tous vos textes.
