Vincular texto
---

Puedes elegir un texto vinculado al crear una tarea.

Así puedes tocar una tarea para saltar rápidamente al texto relacionado.

Al ver el texto, también puedes ver marcadores relacionados con tareas para recordarte que completes las tareas correspondientes.
