Crear libro
---

#### Pasos

1. Ve a la página «Carpetas».
2. Toca «+».
3. Introduce el título del libro.

![](imgs/new_book1.png)

#### Consejos

1. Los libros creados en la página «Carpetas» aparecen en esa página. Los libros creados dentro de una carpeta aparecen en esa carpeta.

2. Toca «Imagen personalizada» para elegir una imagen del álbum como portada del libro.

3. Toca el botón redondo de color situado a la derecha del título del libro para definir el color del título.

4. Toca «Descripción» para añadir una presentación del libro.

5. Toca «Esquema de tamaño de fuente» para usar un tamaño global uniforme o personalizar tamaños locales.
