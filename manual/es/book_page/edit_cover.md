Modificar portada y fuente del libro
---
#### Pasos

1. Toca «Más» en la esquina superior derecha.

2. Toca «Editar» para abrir la página de edición del libro.

![](imgs/edit_cover.png)

#### Consejos

1. Toca «Imagen personalizada» para elegir una imagen del álbum como portada del libro.

2. Toca el botón redondo de color situado a la derecha del título del libro para definir el color del título.

3. Toca «Descripción» para añadir una presentación del libro.

4. Toca «Esquema de tamaño de fuente» para usar un tamaño global uniforme o personalizar tamaños locales.

5. Toca «Esquema de página» para usar un fondo global uniforme o personalizar un fondo individual.
